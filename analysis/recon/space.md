# Recon: js/space.js (1603 lines) — recon unit recon-11

## Description
Defines `classes.managers.SpaceManager` (extends `com.nuclearunicorn.core.TabManager`), the space program manager for the Kittens Game. It holds static data for 13 space "programs" (missions from `orbitalLaunch` through `furthestRingMission`) and 13 planets (cath, moon, dune, piscine, helios, terminus, kairo, yarn, umbra, charon, centaurusSystem, furthestRing) with their space buildings, prices, price ratios, required techs, and effect calculators. Runtime logic covers interstellar route traversal (`routeDays` decremented per tick by `routeSpeed`), per-tick building `action` dispatch (moonOutpost uranium consumption, spaceBeacon relic income, entangler hashrate mining, hydroponics scaling), save/load/reset, offline fastforward, and a custom effect pipeline with a special case for four hash-related effects. The second half of the file is UI: `SpaceProgramBtnController` (mission purchase, oil/manpower price reductions, blackSky challenge price mutations, "in progress"/complete naming), `PlanetBuildingBtnController` (priceRatio exponentiation, cost-reduction effects, sell with 50% refund), `PlanetPanel`/`FurthestRingPanel`, and `SpaceTab` (ground-control panel, hide-completed checkbox, per-planet panels with numerology cycle glyphs, Rorschach/Astronomicon panel). Purchase of a mission starts it (`on=0` until the unlocked planet is reached); missions grant unlocks (planets, further missions, policies, challenges) via `game.unlock`.

Chain: orbitalLaunch→cath+moonMission→…→furthestRing.

6. Constructor, lines 969-1008: `registerMeta` for programs (stackable) and per-planet buildings with custom `getEffect` — four hash effects (`hashrate`, `hashRateLevel`, `nextHashLevelAt`, `hrProgress`) are not multiplied by `on` nor by spaceRatio; other effects × `building.on` × spaceRatio (energy-deficit penalty via `resPool.getEnergyDelta()`); caches `routeDaysDefault` and `spaceBuildingsMap`; `setEffectsCachedExisting()`.
7. `resetState`, lines 1010-1037: only orbitalLaunch unlocked at start; resets planet reached/routeDays/building vals, hideResearched.
8. `save`/`load`, lines 1039-1085: persists programs (val/on/unlocked) and planets (reached/unlocked/routeDays + building val/on/unlocked); on load re-fires `game.unlock(program.unlocks)` / building unlocks in reverse order.
9. `update` per tick, lines 1087-1145: decrements `routeDays` by routeSpeed/ticksPerDay until `reached` (logs "space.newplanet.log.msg", unlocks `spaceBuilding` queue source); unlocks buildings whose `requiredTech` are all researched; calls `bld.action` each tick (if val>0 or entangler), sets `lackResConvert`, then applies `game.calendar.cycleEffectsBasics(bld.effects, bld.name)`; marks missions complete (`on=1`) when their planet is reached.
10. `fastforward(daysOffset)`, lines 1147-1173: offline catch-up for route traversal and entangler gflops→hashrates conversion (capped by stock).
11. Lookups & ratios, lines 1175-1245: `getProgram`/`getBuilding`/`getPlanet` with `metaCache`; `getAutoProductionRatio(useTransferBonus)` = 1+spaceRatio, optionally × prodTransferBonus-transferred build ratio × spaceManufacturing factory craftRatio×0.75; manager-level `getEffect`.
12. `undo`, lines 1247-1279: reverses space building build (full refund via `sellInternal` with refundPercentage 1.0) and sell (re-buys at un-refund) through `classes.ui.space.PlanetBuildingBtnController`.
13. `SpaceProgramBtnController`, lines 1282-1378: prices with oil (`oilReductionRatio`) and manpower (`catpowerReductionRatio`) limited-DR reductions (cap 0.75); blackSky orbitalLaunch → starchart free, all others ×11; visibility by requiredTech + hideResearched; disabled while mission in progress (`val!=0 && on==0`); display name in-progress/complete; `build` sets `on=0`, except rorschachMission completes instantly with log message.
14. `PlanetBuildingBtnController` + panels + `SpaceTab`, lines 1380-1603: building prices use `priceRatio^val` (oil fixed at 1.05^val) × building- and resource-level `CostReduction` effects; blackSky sattelite first copy ×14 with free starchart; build/sell register undo events; `PlanetPanel` shows ETA in title via `toDisplayDays`; `SpaceTab` renders hide-completed checkbox, ground-control program buttons, planet panels titled with cycle glyphs when `numerology` perk researched (moon↔redmoon), and reveals the Rorschach (Astronomicon) panel when rorschachMission is on.

## State & determinism
- Mutable state: `programs[].val/on/unlocked/noStackable`, `planets[].unlocked/reached/routeDays` (+`routeDaysDefault` cache), `planets[].buildings[].val/on/unlocked/effects/lackResConvert/togglable`, `hideResearched`, `metaCache`, `spaceBuildingsMap`; saved under `saveData.space`.
- No `Math.random` anywhere. Time dependence is only game-clock based: route traversal consumes `routeDays` at `routeSpeed/calendar.ticksPerDay`; `fastforward(daysOffset)` advances the same quantities offline; hrHarvester scales on `calendar.darkFutureYears()` and hydroponics/beacon depend on cycle effects via `calendar.cycleEffectsBasics`. All deterministic given game state.

## Port notes / risks
- Two-phase mission lifecycle: buying a mission pays once, sets `val=1, on=0` ("in progress"); `on` flips to 1 only when the unlocked planet's route completes (`update`, lines 1131-1144). rorschachMission/centaurusSystem-style missions with no `unlocks.planet` complete instantly (rorschach logs `space.mission.rorschach.complete.log.msg` in `build`). Port must reproduce `updateEnabled` blocking re-buy while `on==0` and save/load re-firing `game.unlock` for completed items.
- Building price model is non-uniform: generic resources scale by `priceRatio^val` but oil always uses `1.05^val`; two independent discount chains (`<bldName>CostReduction` and `<resName>CostReduction`, both limited-DR with cap 1) multiply prices; program prices instead discount oil via `oilReductionRatio` and manpower via `catpowerReductionRatio` (cap 0.75).
- Custom `getEffect` closure (lines 975-991) is load-bearing: the 4 entangler hash effects must be returned un-multiplied by `building.on` and un-penalized by spaceRatio; everything else is `effects[name] * on * spaceRatio` where spaceRatio < 1 only when energy consumption exceeds production (energy deficit throttling).
- Observability gating: sattelite provides `observatoryRatio` (+satelliteSynergyBonus), auto-upgrades `observatory` buildings via `upgrades.buildings` and `game.upgrade(...)`, and unlocks `outerSpaceTreaty`/`militarizeSpace` policies; its energy flips from consumer to producer (and `on=val`, `togglable=false`) once `solarSatellites` is researched. BlackSky challenge penalizes sattelite starchart output and multiplies sattelite first-copy price ×14 (starchart free) and orbitalLaunch prices ×11 (starchart free).
- Cycle effects via calendar: any building with an `action` gets `calendar.cycleEffectsBasics(bld.effects, bld.name)` re-applied every tick (line 1126) — hydroponics deliberately resets `catnipRatio` to 0.025 in `updateEffects` because the Yarn/Piscine cycle bonus is applied continuously on top; port ordering must match (action → cycle effect) or cycle bonuses will compound incorrectly.
- Entangler action (lines 878-910) is a mini mining simulation: consumes gflops per tick (capped by stock, only if stock non-zero), credits `hashrates`, and derives `hashRateLevel = floor(log(hr/1000)/log(1.6))`; zero-hash saves hide all hash effects; `fastforward` batch-converts gflops→hashrates with the same stock cap — needs exact replication for offline parity.
- Resource-limited production: moonOutpost's `action` rescales its uranium consumption and unobtainium output by `resPool.getAmtDependsOnStock` and sets `lackResConvert` (used by UI to show "lacking resources" state); spaceBeacon's `relicPerDay` depends on blackPyramid ZU effective value, `relicRefineRatio`, entangler hashRateLevel (×0.25 each), and is dampened proportionally when antimatter capacity < 5000.
- Cross-building coupling spans planets (containmentChamber capacity/consumption scale with heatsink val; heatsink/moonBase-storage upgrades mutate other buildings via `upgrades.spaceBuilding`), and `getAutoProductionRatio` imports build-manager ratio + factory craftRatio — port these as effect lookups, not direct copies, to avoid circular init.
- UI shell details to preserve: `hideResearched` checkbox re-renders the whole tab; planet titles gain cycle glyphs only with `numerology` perk (moon maps to redmoon cycle); `PlanetPanel` shows ETA using `toDisplaySeconds`-style display days divided by routeSpeed; FurthestRingPanel exists as a placeholder (has React/WChiral scaffolding commented out); umbra's navigationRelay/spaceShuttle are explicit TBD stubs (empty effects) — keep them inert.
- Undo support: `SpaceManager.undo` handles build (100% refund via `sellInternal`) and sell (re-buy loop with `payPriceForUndoRefund`); build/sell controllers register undo events keyed by `game.space.id` — requires the shared undo infrastructure (`game.registerUndoChange`) to be ported first.
