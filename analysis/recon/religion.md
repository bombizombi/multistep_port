# Recon: js/religion.js (3273 lines) — recon unit recon-08

## Description
This file implements `classes.managers.ReligionManager` (extends `com.nuclearunicorn.core.TabManager`), the faith/praise/ziggurat side of Kittens Game, plus all of its UI controllers and the tab itself. It owns four metadata collections — `zigguratUpgrades` (10 ZU defs), `religionUpgrades` (11 RU defs), `transcendenceUpgrades` (11 TU defs, tier-gated by `transcendenceTier` / "TT"), and a separate `classes.religion.pactsManager` holding 9 pact defs. Core economies: faith→worship (praise), worship→epiphany (adore/resetFaith), epiphany→TT (transcend with an exponential price curve), alicorn→necrocorn corruption (markers), and pact necrocorn debt with a "fractured" failure state. It also implements a generic `TransformBtnController` (unicorns→tears, alicorns→time crystals, TCs→relics) and a full undo pathway for every religion action. Feature flags `MAUSOLEUM_PACTS` and `DARK_PARACOSM` gate the newest content (black pyramid pact effects, mausoleum, darkParacosm). The file is self-contained UI-wise: ReligionTab, panels, widgets and button controllers all live here.

## Port notes / risks
- Praise formula: `worshipGained = faith.value * (1 + getApocryphaBonus())`, worship capped at `Number.MAX_VALUE`, and faith is reset to `0.0001` (not 0 — deliberate, for autoclicker/production continuity). Keep the residue.
- Faith cap logic: unicornTears challenge reward gives `faithMax = 5 + 3*TT^1.5` (TT<100, else 3000) ×2 via unicornTomb's `calculateEffects`; the challenge instead caps tears/unicorns/alicorns. Effects are mutated in place per def — the F# port must replicate the mutable `self.effects = {...}` replacement semantics (skyPalace/unicornUtopia/sunspire replace the whole effects object).
- Transcendence difficulty scaling: total price for tier T = `getInverseUnlimitedDR(exp(T)/10, 0.1)`; next-level price is the difference, so cost grows ~e^T. Transcend is strictly one level per click and re-runs `calculateAllEffects` + blackPyramid `cashPreDeficitEffects`. Legacy save migration (`tcratio`) must be preserved or old saves lose TT.
- Solar Revolution: uncapped = `unlimitedDR(faith, 1000)/100`; cap = `10 + solarRevolutionLimit + (atheism researched ? TT : 0)`; then `limitedDR(...)` × `(1 + faithSolarRevolutionBoost)`. RU `solarRevolution.calculateEffects` is re-run from the tab's `update()` every render tick, not only on purchase — a port that computes effects only on buy will show stale bonuses.
- Pact costs per year: every pact sets `priceRatio = 1` (enforced in pactsManager ctor); consumption is `necrocornPerDay = pactNecrocornConsumption` effect (-0.0005/pact/day). Buying a pact adds `+0.5` necrocorn deficit per unit unless `pactNecrocornUpfrontCost > 0` (upfrontPayment policy). Without Siphoning, deficit is repaid at `0.15*(1 + deficitRecoveryRatio)` extra consumption; with Siphoning, generated necrocorns repay debt first (`repayDebtOnNecrocornGeneration`).
- Debt penalty: `getDebtPenaltyRatio` is linear from 1 (no debt) to 0 at `fractureNecrocornDeficit = 50`, with `smallDebtPunishmentExemption` lower bound; blackPyramid's entire effect set is multiplied by this ratio (except deficitRecoveryRatio).
- Fracture failure state: at deficit >= 50 (or explicitly) all pacts are zeroed and locked, `fractured` activates (pyramid effects -0.5), all kitten job skills wiped, alicorns zeroed. Note `necrocornDeficitPunishment` is duplicated verbatim in both ReligionManager (1493-1518) and pactsManager (2790-2816) — dedupe opportunity in the port.
- Corruption mechanics: `maxAlicornsToCorrupt = ceil(alicorns) - 1` keeps at least 1 alicorn alive or per-tick generation would stop; corruption progress clamps at 1 and stalls when alicorns run out; each conversion triggers `game.upgrade` of skyPalace/unicornUtopia/sunspire (needed to re-eval alicornPerTick gating).
- `necrocornFastForward` is the highest-risk port: two naive variants + an outer edge-case loop that re-simulates in chunks whenever continuous pact consumption would cross the exist-necrocorn threshold (0, or 1 with feedingFrenzy). Preserve `ticksPerDay = times/days` assumption and the siphoning threshold-projection loop exactly; original TODOs call for a test suite (test/necrocorns.test.js).
- Feature-flagged content (`MAUSOLEUM_PACTS`, `DARK_PARACOSM`) silently zeroes/locks defs when off; undo for buyPact/transform events must round-trip with the UI controller classes (PactsBtnController.build mutates deficit, breaks ironWill, un-jams blackPyramid) — the undo unit depends on controllers being ported with identical side-effect ordering.
