# Recon: js/challenges.js (1328 lines) — recon unit recon-12

## Description
This file implements the Kittens Game challenge system in three layers. The core is `classes.managers.ChallengesManager` (a `TabManager` subclass) holding 10 static challenge definitions (ironWill, winterIsComing, anarchy, energy, atheism, 1000Years, blackSky, pacifism, unicornTears, postApocalypse), each with an effects map, `stackOptions` controlling reward scaling across repeat completions (noStack / Limited Diminishing Returns / magnitude cap), a `calculateEffects` hook that swaps values depending on whether the challenge is currently active, and completion checks evaluated either every tick or at run reset. The manager tracks per-challenge `unlocked/pending/active/researched/on` state, researches completed challenges (incrementing `on`, firing `actionOnCompletion` and unlocks), and implements the "apply pending challenges" transition which snapshots resources/kittens into `classes.reserveMan` before calling `game.resetAutomatic()`. The remainder is UI: a `ChallengeBtnController`/`ChallengePanel` for toggling pending challenges, a `ReservesPanel` for viewing/reclaiming stashed resources and cryo-kittens, per-challenge `ChallengeEffectsPanel`s, and the `ChallengesTab` that composes them. Several challenges mutate other managers' metadata as side effects (building `priceRules`, policies, achievement badges), and ironWill is a pseudo-challenge whose active flag simply mirrors `game.ironWill`.

## Port notes / risks
- Stacking semantics must be replicated exactly: order is `base * on`, then `noStack` bypass, then `LDRLimit` (game.getLimitedDR), then `capMagnitude` clamp (LDR applied before cap). Repeat-completion balance depends on it.
- `calculateEffects` are recalculation hooks with side effects beyond setting numbers: 1000Years/blackSky/pacifism call `game.upgrade(self.upgrades)` on every recalc (explicit "hack"), and blackSky/pacifism/postApocalypse toggle `meta.priceRules` on other managers' buildings — the F# effect pipeline must preserve evaluation order relative to price calculation.
- Every def has an active/inactive branch pair (rewards zeroed and penalties added while active); anarchy and unicornTears compute values from `self.on` inside the active branch, so they are not simple static pairs.
- Two distinct completion paths: `checkCompletionCondition` polled in `update()` for active challenges, and `checkCompletionConditionOnReset` polled only in `onRunReset()` inside `applyPending` (atheism, pacifism). Pacifism's on-reset hook deliberately doubles as a badge hook (cleanPaws) that runs even when the completion condition fails.
- `applyPending` is the transition core: confirm dialog (with special winterIsComing+postApocalypse+cryochamber warning), reserve snapshot taken before reset, chronosphere zeroed, cryochambers preserved only when postApocalypse is pending and it's not an ironWill apply, village leader cleared if anarchy pending, then `game.resetAutomatic()`.
- Reserve restore has asymmetric semantics in `addReserves`: capped resources take `Math.max(current, reserved)` while uncapped ones add; timeCrystal is dropped; reclaiming sets `startedWithoutChronospheres = false` (achievement-invalidating) and unlocks `usedCryochambers`.
- ironWill is a pseudo-challenge: no effects; `active` is forced to `game.ironWill` every `update()`; clicking its button immediately invokes `applyPending(true)` instead of toggling pending, which also changes reserve math (kittens still reserved, cryochambers zeroed).
- unicornTears is feature-flag-gated: when the flag is off, `update()` locks/kicks the player out and `calculateEffects` zeroes all effects; its `resWeights` table uses `-Infinity` sentinels (unicorns/tears/alicorn/megalith) and careful NaN hygiene — watch float semantics in the port.
- Save/load legacy compat: deprecated `currentChallenge` string, `researched`→`on=1` migration, reserve kittens deserialized iterating backwards with `unshift`; save format also emits an unused `ironWillClaim` field from `getSaveData`.
- UI couples to game state: shift-click multiplies effect display (`multiplyEffects`), `detailedChallengeInfo` toggles per-challenge effect panels, the ascoh perk gates exact reserve amounts, and chronophysics research forces the reserves panel visible.
