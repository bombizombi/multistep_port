## Description

## State & determinism
- Mutable state — stats.js: `stats[i].val/.unlocked`, `statsCurrent[i].val/.unlocked` (mutated by resetState, load, getStatCurrent recompute, resetStatsCurrent, unlockAll, and StatsTab.update). void.js: `faction` (null until loaded), `voidUpgrades[].val/.on/.unlocked/.researched` (saved but never reloaded). math.js: fully stateless (prototype methods, no instance fields).
- Math.random usage in math.js (game.rand: none — this file uses the global RNG exclusively):
  - L11 `uniformRandomInteger`: 1 draw per call.
  - L17-18 `standardGaussianRandom`: 2 draws per call (while-loops redraw only on exact 0.0 — astronomically rare but must be modeled: redraw until in (0,1)).
  - L25 `irwinHallRandom`: passes `Math.random` by reference as baseDistribution — `trials` draws in loop path, or 2 draws per rejection attempt in Gaussian path.
  - L34 `binominalRandomInteger` base fn: 1 draw per loop iteration (0 draws if p<=0 or p>=1 — short-circuit happens BEFORE any draw); Gaussian path: 2 draws per attempt via L59.
  - L59 rejection loop: 2 draws per attempt (through standardGaussianRandom), unbounded retries.
  - L101 `geometricRandom`: 1 draw per call (while-loop redraws only on exact 0.0).
- Draw-order sensitivity: village.js:1053-1096 fires these in sequence (unicorns → geometric bloodstone → bloodstone binomial → gold binomial + 2×irwinHall → ivory binomial + 2×irwinHall → furs 2×irwinHall); diplomacy rolls several binomials per trade. A differing draw count per call desyncs ALL subsequent loot — the F# RNG must be a single injectable stream consumed in exactly this order.
- Float accumulation: loop path in loopOrGaussianApproximation accumulates a JS float sum (irwinHall results are fractional); log1p sums coefficients strictly descending (result = c[n], then n-1 → 1); globalMean/SD computed inline as trials*mean and Math.sqrt(trials*variance). Operation order must be preserved for bit-exact results.
- Hidden display mutation: StatsTab.update (L218-242) recalculates calculated stats, auto-unlocks nonzero stats, and does totalResets val++/val-- around rendering — transient, but observable if save happens mid-render or if unlock is expected.

## Port notes / risks
- RNG draws per call: uniformRandomInteger = 1; standardGaussianRandom = exactly 2 (cos branch ONLY — do not "fix" to a sin/cos variate pair, that doubles draw consumption and changes everything downstream); geometricRandom = 1 (redraw only on exact 0.0); irwinHall = trials draws when trials<100 or the 5σ condition trips, else 2 per rejection attempt; binominal = 0 draws when p<=0 or p>=1, otherwise like irwinHall with a 1-draw-per-iteration base.
- Math.round (L61, L9-10) rounds .5 toward +∞; F# `round` is banker's rounding — must implement half-up rounding explicitly in the discrete Gaussian path and in uniformRandomInteger bounds.
- log1p (math-03): series branch only for |p|<=0.25; term count n = 1 + ceil(-52*Math.LN2 / Math.log(|p|)) — replicate exactly (System.Math.Log/Math.Ceiling, LN2 constant) since geometricRandom divides by log1p(-p) and calendar.js:885 feeds log1p bounds into the RNG engine; wrong n shifts float results and desyncs loot.
- The rejection loop is `while(true)` with no attempt cap; the 5σ guard makes it terminate in practice, but port it as a faithful infinite loop (with RNG stream), not a bounded approximation.
- Irwin-Hall loop path returns a fractional float (gold/ivory/furs/spice amounts are non-integer); binomial loop path sums 0/1 so it is integral — keep return types distinct in F# (float vs int) per call site as in JS semantics.
- Stats used by achievements: totalYears (achievements.js:230) and totalResets (achievements.js:282, >= 50 threshold); stat visibility is gated on `val != 0` auto-unlock, so a stat stays "???" at zero — preserve unlock semantics, not just values.
- getStatCurrent recomputes AND mutates val on every read; in F#, model calculated stats as functions, but only non-calculated vals are persisted (save filters to name+val, calculate defs keep val: 0 in saves).
- void.js quirk: `load()` restores only `faction` and silently drops the saved `vu` array (spaceCathedral state lost on reload); spaceCathedral has no callers (latent), RorshachWgt renders an empty string. Port as-is (faithful) and flag rather than "fixing", or agree a deliberate fix.
- Naming: JS class `com.nuclearunicorn.game.Math` collides conceptually with F#'s `Math`/`System.Math` — name the F# module e.g. `GameMath`/`KittensMath` to avoid shadowing.
