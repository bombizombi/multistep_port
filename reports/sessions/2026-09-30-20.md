## What was built

- **Save-blob parser** (`parseSaveBlob`): raw `{` JSON or `decompressLZData`
  (base64 first, UTF-16 fallback) → System.Text.Json → a small `JsValue` tree.
- **`applySaveBlob`** — the full game.load() order: resetState → resources →
  village (kittens: `seed` → loadSeeded identity regeneration, else
  `ssn` → loadCompressed base-100 split; traits rebuilt via reversed
  unshift) → calendar → console filters → telemetry guid → challenges
  (+reserves, researched&&!on→1, unlock re-fires) → workshop → diplomacy →
  buildings → science → achievements → religion (+legacy tcratio tier) →
  space (+reversed program/building unlock re-fires) → time (cfu tri-states,
  timeBoiler←blastFurnace, queueSources, gainTemporalFlux) → game section
  (karmaKittens/ironWill) → calculateAllEffects → updateMaxValueAll →
  updateCaches → village.updateHappines.
- **The headless orig quirk that shaped everything**: `game.load()` THROWS in
  `queue.updateQueueSourcesArr` — a bare `self` at js/time.js L2107
  (ReferenceError in Node; browsers have `self` = window so nobody noticed).
  The catch aborts the managers loop: **prestige/stats/void never restore,
  afterLoads never run, and `currentSaveIsBroken` turns every later save()
  and autosave into a no-op** (save() early-returns before resetting
  ticksBeforeSave). The FS loader replicates this exactly.
- **Per-kitten RNG churn**: `new Kitten()` (seedless, used by village.load)
  rolls identity from the GAME rand — 7-11 draws per saved kitten, burned even
  though loadSeeded/loadCompressed then overwrite the identity. FS burns the
  same draws (reversed order).
- **game-15 export**: `saveexport` = PLAIN `JSON.stringify(save())` →
  `compressToBase64`. The export form differs from the storage form because
  JSONreplacer's loose `value == undefined` also drops **nulls**: the plain
  form keeps `server.motdContent`, `village.currentBiome/lastBiome`,
  `calendar.weather`, `buildings[].isAutomationEnabled` (warehouse, calciner,
  steamworks, oilWell, factory, reactor), `time.cfu[].isAutomationEnabled`,
  `void.faction`, `game.lastBackup`. `buildSaveStringMode(plain)` emits both
  forms. Import = decompress → `{` integrity check → LCstorage ← lz blob →
  load (`importfile` resop both drivers).
