## Discoveries worth remembering

1. **Orig already runs headless in Node** — its own jest bootloader (`test/setup.js`,
   portable declare + mocked dojo) proves it; `test/game.test.js` shows the controller
   API for driving actions. This de-risks oracle-01 substantially.
2. Tick is a plain `game.tick()` on a `setInterval`/Web-Worker timer — headless we drive
   it synchronously; logical time only.
3. Village combat code contains an internal `deterministic` flag (js/village.js L2251) —
   orig has partial determinism hooks already.
4. `strategies/temple-baseline.txt` (3549 moves, temple at tick 626,976) is in the
   scenario format we want — becomes the long-run scenario after vocabulary mapping.
5. `elmish-land init` is interactive and crashes on non-TTY stdin (`printf '1\n' |` works);
   its generated `global.json` pins SDK `11.0.100` exactly which fails on the installed
   `11.0.100-rc.1` — overwritten with root-style pin (D008). Also: init/restore do NOT
   create the fable tool manifest; added `.config/dotnet-tools.json` (fable 5.17.0).
