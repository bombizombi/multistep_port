   difference.

   stack — keep provably consistent or drop the mirror (decision needed at game-11);
   manager construction order is load-bearing; save blob is LZ-compressed v15 with a
   v1→v14 migration chain.

   L1521) — exact 32-bit RNG and roll order pinned for the port; combat has an internal
   `deterministic` flag.
4. **buildings/religion/jobs:** `calculateEffects` is dispatched by NAME and writes back
   into shared static metadata — the F# model needs mutable per-instance effect caches.
5. **ui.js showstopper:** UI code secretly mutates game state (totalClicks stat,
   `unlockedSchemes`, `opts.notation`, console filters) and live shift-key state feeds
   effect display math — the Elmish port must relocate these to explicit messages.
6. **workshop.js:** 143 upgrades / 23 crafts in orig vs 142/20 in the old project's
   spec — first concrete verify-01 discrepancy (specs are NOT trustworthy as-is).
7. **Boot (index.md):** strict script order config → i18n → dictionaries → core →
