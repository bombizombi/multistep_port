## State-model correction (the session's real find)

My first F# run seeded the cap context from the BaseEffects table — and diverged. The
fixture showed why: **orig's global effects cache is EMPTY before the first tick**
(`updateCaches` hasn't run), so `resop caps` at tick 0 yields all-zero caps except the
effect-free specials. The runner now uses `zeroCapContext` (matching orig's t0 state);
`baseEffectsCapContext` (BaseEffects-seeded) is the documented post-cache context that
game-08 will make real. BaseEffects data itself is cross-checked against the
fresh-100-ticks fixture `m` values (catnip 5000 … temporalFluxMax 3000 from
time.js — the latter lives in the TIME manager's effectsBase, not buildings').
