## Debugging findings (all recorded in D011 / D012 / discrepancies.md)

1. Node ≥20 has a read-only `globalThis.navigator` — jsdom mirror needs `defineProperty`.
2. GamePage looks managers up on `window["classes"]["managers"]` — jest's window IS the
   global; in Node the declare namespace must be mirrored onto the jsdom window.
3. Modern building controller's `build()` returns `undefined` on all paths — success
   detection uses state delta; failed buys/crafts/assigns are logged with reasons.
4. Gather catnip = exactly `catnip.value++`; field production 0.125/tick; wood = 100
   catnip/unit; hut = 5 wood; science cap 250 base + 250 per library.
5. **OBS-1 (SOLVED):** science production was gated on job `calculateEffects` (scholar
   modifiers `{science: 0.035}`) which orig triggers only through its UI render pass
   (`game.upgrade({jobs})`). Harness mirrors that side effect after building purchases
   that unlock jobs (D012) — orig untouched. **Port requirement:** F# core must call job
   `calculateEffects` at unlock time (village-04 contract).
6. **OBS-2 (observed):** `village.assignJob` bumps `jobRef.value` by `amt` even when
   `sim.assignJob` assigned fewer kittens — faithful orig quirk, captured in fixtures,
   must be reproduced by the port (village-04).
7. Autosave ("Game saved") writes to in-memory LCstorage — deterministic; rngDraws per
   tick ~15 confirms full PRNG capture (game.rand and bare Math.random both flow through
   the single patched stream).
